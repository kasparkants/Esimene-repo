# Tutvustus - Kaspar

## Tere!

Minu nimi on Kaspar Kants. Ma olen 20-aastane noormees pärit Niinjast (lihtsam öelda Martnast, sest see on natuke suurem küla samas kandis.) Lõpetasin 2025. aastal Läänemaa Ühisgümnaasiumi. Siin saab isegi näha kuidas ma tunnistuse kätte saan: ([Youtube](https://www.youtube.com/watch?v=QZ3CeWQNjTs&t=9s))
Peale gümnaasiumit astusin Haapsalu Kolledži sisse, aga võtsin kohe ajateeenistuse tõttu akadeemilise puhkuse. Nautisin suve ja nüüd hakkan taas õppima :D.

Lisan siia lõppu paar plakatit/disaini, mida olen aastate jooksul teinud nii vabal ajal, kui ka kooli jaoks.
